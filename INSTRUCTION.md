1. How to run containers with docker-compose.

docker-compose up -d  # The command should be run in directory with docker-compose.yml

2. How to stop containers with docker-compose.

docker-compose down

3. How get access to the app from browser.

http://localhost:8000/

4. How to check logs the app

docker-compose logs

5. How to confirm the app is running

docker-compose ps
